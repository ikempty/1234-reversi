      • 基本ルール：
        通常のリバーシと同様、相手の駒を挟んで裏返します。
      • 駒：
        各プレイヤー32個。初期配置の2個を除いた30個を手持ちとします。2×2マスの範囲内で、縦横につながる1〜4個の駒を一度に置けます。
      • 配置条件：
        置く駒のうち、1個でも相手の駒を挟めれば配置できます。配置後はそれぞれ独立した駒として扱います。
      • パス：
        手持ちの駒がない、または配置できない場合はパスとなります。
      • 勝敗：
        双方が駒を置けなくなった時点で、盤面上の駒が多い方の勝ちです。
